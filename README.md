# AfnoDokan
Your Shop, Your Way!
**Afno Dokan** is a modern **e-commerce frontend application** built with the latest web technologies using **Next.js App Router**. 
This project demonstrates frontend architecture, reusable components, form handling, admin workflows, and production-ready deployment on Vercel.

---

## 🌐 Live Demo

* **Main Website:** [https://afno-dokan.vercel.app/](https://afno-dokan.vercel.app/)
* **Admin Panel:** [https://afno-dokan.vercel.app/admin](https://afno-dokan.vercel.app/admin)

---

##  Tech Stack (Frontend)

### Core

* **Next.js 16** (App Router)
* **React 19**
* **TypeScript**

### Styling & UI

* **Tailwind CSS 4**
* **Radix UI** (accessible UI components)
* **Lucide React** (icons)
* **Framer Motion** (animations)
* **Sonner** (toast notifications)

### Forms & Data Handling

* **Formik** – form state management
* **Yup** – schema-based validation
* **Axios** – API requests

## Installation

### Clone the repository

```bash
git clone https://github.com/jagat05/afno-dokan.git
cd afno-dokan/client
```

### Install dependencies

```bash
npm install
```

---

## ▶️ Run Locally

```bash
npm run dev
```
